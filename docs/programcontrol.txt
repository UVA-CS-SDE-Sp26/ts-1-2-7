Use Mockito for unit testing
- Create a dummy object for classes
- Bugs in classes will not affect testing

ProgramControl.java tests
- Planning: For testing, there are 5 cases that are needed to be checked. These cases include a no argument test, a valid single argument test,
a two valid argument test, an invalid file number test, and an invalid alternate key test. Because ProgramControl.java calls both FileHandler.java
and cipher.java, Mockito should be used to create dummy objects for these classes.
- Psuedocode:

noArgTest()
    String argument with no arguments
    Create mock cipher class
    Create mock FileHandler class
    Call ProgramControl class
    Run main
    Verify with Mockito and assertEquals

oneArgTest()
    String argument with one argument
    Create mock cipher class
    Call ProgramControl class
    Run main
    Verify with assertEquals

twoArgTest()
    String argument with two arguments
    Create mock cipher class
    Call ProgramControl class
    Run main
    Verify with assertEquals

invalidNumTest()
    String argument with an invalid number argument
    Create mock cipher class
    Call ProgramControl class
    Verify with assertThrows

invalidFileTest()
    String argument with an invalid file argument
    Create mock cipher class
    Call ProgramControl class
    Verify with assertThrows

FileHandler.java tests

Constructor Tests:
1. testConstructorWithParameter - Creates FileHandler with custom path
2. testDefaultConstructor - Creates FileHandler with default "data" path

listFiles() Tests:
1. testListFiles_WithMultipleTxtFiles - Returns 3 .txt files
2. testListFiles_SortedAlphabetically - Returns files in alphabetical order
3. testListFiles_FiltersNonTxtFiles - Ignores non-.txt files
4. testListFiles_DirectoryNotFound - Throws error when directory doesn't exist
5. testListFiles_NoTxtFiles - Throws error when only non-txt files exist
6. testListFiles_EmptyDirectory - Throws error when directory is empty

reader() Tests:
1. testReader_ValidFile - Reads and returns file content correctly
2. testReader_EmptyFile - Returns empty string for empty file
3. testReader_FileNotFound - Throws error when file doesn't exist
