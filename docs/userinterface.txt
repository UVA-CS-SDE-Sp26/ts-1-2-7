User Interface should display 3 different things depending on how project was called:
1. No arguments - display list of files with "0" + file number and then the filename
2. 1 argument (specific file called) - display contents of file deciphered using default cipher
3. 2 arguments (specific file and cipher) - display contents of file deciphered using called cipher
